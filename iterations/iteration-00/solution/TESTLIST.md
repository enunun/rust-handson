# テストリスト

## 単体テスト

### lexer

- [x] 空の文字列からは，空のトークン列を返す
- [x] `42`からは，整数42を1つ返す
- [x] `+-*/`からは，4つの演算子を順に返す
- [x] `(,)`からは，左括弧，コンマ，右括弧を順に返す
- [x] `VALUES`からは，キーワードVALUESを返す
- [x] `values`と`Values`からも，キーワードVALUESを返す
- [x] `" 1 +\n2 "`のように，トークンの前後と間の空白と改行を読み飛ばす
- [x] `1 ? 2`は，解釈できない文字の位置3のエラーになる
- [x] `1 SELECT`は，VALUES以外の単語の先頭の位置3のエラーになる
- [x] `9223372036854775807`(`i64`の最大値)は，整数になる
- [x] `9223372036854775808`は，`i64`に収まらないので位置1のエラーになる

## 結合テスト

### tokenize

- [x] `values (1, 2 + 3)`から，使用例のトークン列を返す
- [x] `VALUES (1 ? 2)`は，位置11のエラーになる
