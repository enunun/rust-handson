# テストリスト

## 単体テスト

### storage::buffer

- [x] 取得したページは，ディスクのページと同じ内容である
- [x] 枠にあるページをもう一度取得しても，ディスクを読まない
- [x] ピン留めされたページは追い出さない．すべての枠がピン留めされていれば`AllPinned`になる
- [x] `PageGuard`を捨てるとピンが外れ，そのページを追い出せる
- [x] 書き換えたページは，追い出すときにディスクへ書き戻す．読んだだけのページは書き戻さない
- [x] 新しいページはディスクの末尾に加わり，書き換えた内容を読める
- [x] `flush_all`は書き換えたページだけを書き戻し，2回目は何も書かない
- [x] プールを捨てると，書き換えたページがファイルに残る
- [x] クロック方式は，参照ビットの立った枠を1度だけ飛ばす
- [x] クロック方式は，ピン留めされた枠を選ばない．すべてピン留めされていれば`None`になる

### storage::heap

- [x] (変更)ページの数は`BufferPool`から読む

### error

- [x] すべての枠がピン留めされたエラーは，`XX000`と`no unpinned buffers available`になる

## 結合テスト

### persistence

- [x] バッファプールの枠より多いページを持つ表も，更新して開き直すと，すべての行が読める

### そのほか(既存)

- [x] ページをバッファプールで読み書きするようにしたあとも，引き継いだテストがすべて通る
