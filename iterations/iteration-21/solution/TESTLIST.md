# テストリスト

## 単体テスト

### storage::buffer

- [x] 複数のスレッドが，1つのプールのページを同時に読める．枠より多いページを，追い出しながら読んでも内容は正しい

### database

- [x] トランザクションの中でセッションを捨てると，そのトランザクションは中止になる

## 結合テスト

### session

- [x] セッションごとに，トランザクションの状態を持つ
- [x] ほかのセッションがコミットしていない行は見えず，コミットすると見える
- [x] 複数のスレッドのセッションが同時に行を加えても，すべての行が残り，データディレクトリを開き直しても残る

### server

- [x] 2つのクライアントが同時に接続できる．一方のトランザクションの中で加えた行は，他方からコミットするまで見えない

### そのほか(既存)

- [x] (変更)`Database::execute`を呼んでいたテストは，`Session::execute`を呼ぶ
- [x] (変更)`handle`には，`&mut Database`でなく`Arc<Database>`を渡す
- [x] 引き継いだテストがすべて通る
