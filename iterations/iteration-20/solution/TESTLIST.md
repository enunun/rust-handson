# テストリスト

## 単体テスト

### server::message

- [x] 起動のメッセージから，名前と値の組を読む
- [x] SSLの要求は暗号化の要求として読み，知らないプロトコルの番号はエラーにする
- [x] `Query`と`Terminate`を順に読み，接続が閉じたら`None`を返す
- [x] 知らない種類のメッセージはエラーにする
- [x] サーバーのメッセージは，種類の1バイトとビッグエンディアンの長さで始まる
- [x] `DataRow`は`NULL`をバイト数-1で書く
- [x] `RowDescription`は，列ごとに名前，型OID，型の大きさを書く
- [x] `ErrorResponse`は，フィールドの種類と文字列の組を並べ，0のバイトで終わる

### server::connection

- [x] 起動には，`AuthenticationOk`，`ParameterStatus`，`ReadyForQuery`(`I`)で答える
- [x] SSLの要求には`N`で答え，続く起動を受け付ける
- [x] `Terminate`を受け取るまで，問い合わせに答える
- [x] 問い合わせの結果は，列の型OIDとテキスト形式の値で返す．`NULL`の値はバイト数-1で，値がすべて`NULL`の列は`text`である
- [x] `;`で区切った文を，順に実行する
- [x] 空の問い合わせには`EmptyQueryResponse`を返す
- [x] エラーになったら残りの文を実行しない．エラーの位置は，問い合わせの先頭から数える
- [x] `ReadyForQuery`で，トランザクションの状態(`I`，`T`，`E`)を返す

## 結合テスト

### server

- [x] クライアントは，問い合わせの結果の列の名前と，テキスト形式の値を受け取る
- [x] クライアントは，エラーのSQLSTATEと位置を受け取る
- [x] トランザクションは，複数の問い合わせにまたがる
- [x] クライアントが接続を終えると，サーバーの`handle`は`Ok`を返す

### そのほか(既存)

- [x] 引き継いだテストがすべて通る
