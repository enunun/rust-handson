# テストリスト

## 単体テスト

### index::key

- [x] `INTEGER`と`BIGINT`の値を符号化したバイト列は，最小値から最大値まで数の順に並び，復号すると元に戻る
- [x] `INTEGER`は，符号ビットを反転した4バイトのビッグエンディアンになる
- [x] `BOOLEAN`は偽，真の順に並ぶ．`0`と`1`以外のバイトは復号できない
- [x] `VARCHAR`は，空の文字列，接頭辞，日本語を含めて文字の順に並ぶ．UTF-8でないバイト列は復号できない
- [x] 長さの違うバイト列は，整数に復号できない

### index::btree

- [x] 空の木には，どのキーもない
- [x] 加えたキーを`get`で引ける．ないキーは`None`になる
- [x] `range(..)`は，加えた順によらず，キーの順に返す
- [x] 葉がいっぱいになると分割され，根が内部ノードになる．分割のあともすべてのキーを引ける
- [x] 長いキーで内部ノードもいっぱいにすると，内部ノードも分割され，木が3段になる
- [x] 範囲は，含む，含まない，限りがない始まりと終わりを守る．範囲に項目がなければ何も返さない
- [x] 同じキーの項目は`RowId`の順に並び，`get`は最も小さい`RowId`を返す
- [x] `delete`はキーと`RowId`の一致する項目だけを消す．ない項目なら`false`を返す
- [x] 分割のあとで多くの項目を消しても，残りの項目を順に読める
- [x] 2000バイトを超えるキーは`KeyTooLarge`になり，2000バイトのキーは入る
- [x] 3枠のバッファプールでも，3000個の項目を入れて読める
- [x] 葉のノードは，ヘッダー(種類，項目の数，右隣の葉)と項目のバイト列になり，復号すると元に戻る
- [x] 分割の位置は，項目のバイト数がほぼ半分になる位置で，どちらにも1つ以上の項目が残る
