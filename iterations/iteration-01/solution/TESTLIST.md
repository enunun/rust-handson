# テストリスト

## 単体テスト

### parser

- [x] `VALUES (1)`からは，整数1を1つ持つ`Values`を返す
- [x] `VALUES (1, 2, 3)`からは，3つの式を順に持つ`Values`を返す
- [x] `+`，`-`，`*`，`/`は，それぞれの二項演算の構文木になる
- [x] `1 - 2 - 3`は`(1 - 2) - 3`になる(左結合)
- [x] `1 + 2 * 3`は`1 + (2 * 3)`になる(乗算が先)
- [x] `(1 + 2) * 3`は括弧の中が先になる
- [x] `-2 * 3`は`(-2) * 3`になる(単項の`-`が先)
- [x] `VALUES (1 +)`は，構文エラーになる
- [x] `VALUES ()`は，構文エラーになる
- [x] `VALUES 1`は，構文エラーになる
- [x] `VALUES (1) 2`のように文のあとにトークンが残ると，構文エラーになる

### eval

- [x] 整数`7`は，値`7`になる
- [x] `6 + 3`，`6 - 3`，`6 * 3`，`6 / 3`は，それぞれ`9`，`3`，`18`，`2`になる
- [x] `-(4 - 6)`は`2`になる
- [x] `7 / 2`は`3`，`-7 / 2`は`-3`になる(0の方向に切り捨てる)
- [x] `1 / 0`は，0での割り算のエラーになる
- [x] `2147483647`は値になり，`2147483648`は範囲外のエラーになる
- [x] `2147483647 + 1`は，範囲外のエラーになる
- [x] `-2147483647 - 2`は，範囲外のエラーになる
- [x] `65536 * 32768`は，範囲外のエラーになる
- [x] `-(-2147483647 - 1)`は，範囲外のエラーになる
- [x] `(-2147483647 - 1) / -1`は，範囲外のエラーになる

## 結合テスト

### values

- [x] `VALUES (1 + 2 * 3, -(4 - 6) / 2)`は，列名`COLUMN1`，`COLUMN2`と1行`7`，`1`の表になる
- [x] `VALUES (1 ? 2)`は，字句解析のエラー(位置11)になる
- [x] `VALUES (1 +)`は，構文解析のエラーになる
- [x] `VALUES (1 / 0)`は，0での割り算のエラーになる
