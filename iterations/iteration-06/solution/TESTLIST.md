# テストリスト

## 単体テスト

### format

- [x] `CREATE TABLE`と`INSERT`の結果は，コマンドタグ`CREATE TABLE`と`INSERT 0 2`になる
- [x] 列の幅は，見出しと値のうち最も長いものに合わせる．数値は右，文字列は左に寄せる
- [x] 見出しは中央に寄せる
- [x] `NULL`は空，真偽値は`t`と`f`になる
- [x] 行がない結果は`(0 rows)`になる．1行なら`(1 row)`になる
- [x] 幅は文字の数で数える

### repl

- [x] `;`で文が終わる
- [x] 最後の`;`のあとの文字は，まだ終わっていない残りになる
- [x] 1行に複数の文を書ける
- [x] 引用符の中の`;`では文が終わらない
- [x] 文は複数の行にまたがってよい

## 結合テスト

### repl

- [x] `CREATE TABLE`，複数行の`INSERT`，`SELECT`を順に実行し，コマンドタグと表を書く
- [x] エラーは`ERROR:  メッセージ`を書き，次の文を実行する
- [x] 入力の終わりに残った`;`のない文も実行する
- [x] 空の文は何も書かない
- [x] 端末から入力するときは，プロンプト`ferrodb>`と`->`を書く
