# テストリスト

## 単体テスト

### wal

- [x] 書いたレコードを，書いた順に読み戻せる．読んだレコードの位置は，書いたときに返った位置と同じである
- [x] レコードは，内容のバイト数とCRC-32のあとに内容を置く
- [x] 途中で終わるレコードと，CRC-32の合わないレコードからあとは読まない
- [x] リカバリは，最後のチェックポイントのあとのページの内容をファイルに書き，ないファイルの記録は飛ばす．コミットの記録のないトランザクションは中止になり，次の番号はその後ろから振る
- [x] ログのファイルを開くと，正しく読めた終わりより後ろを捨てて，そこから書く

### storage::buffer

- [x] 書き換えたページは，捨てるときにログへ記録され，追い出す前にログがファイルに届く

### sql::parser

- [x] `CHECKPOINT`

### format

- [x] `CHECKPOINT`のコマンドタグ

## 結合テスト

### recovery

- [x] プロセスを強制終了しても，コミットした行は残り，コミットしていない行は見えない
- [x] チェックポイントのあとの削除と追加も，強制終了のあとにやり直される
- [x] ログの末尾の壊れたレコードは読み捨て，その後ろに新しいレコードを書ける
- [x] メモリーのデータベースの`CHECKPOINT`もコマンドタグを返す

### そのほか(既存)

- [x] (変更)データディレクトリに`wal`がある
- [x] 引き継いだそのほかのテストがすべて通る
