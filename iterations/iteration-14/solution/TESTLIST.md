# テストリスト

## 単体テスト

### storage::disk

- [x] メモリー用の`DiskManager`は，加えたページに書いた内容を読める．加えたばかりのページは0で埋まっている
- [x] ファイル用の`DiskManager`も，同じ操作で同じ結果になる
- [x] ファイル用の`DiskManager`は，開き直してもページの数と内容が残る．ファイルの大きさはページの数の8192倍である
- [x] ないページを読むとエラーになる

### storage::heap

- [x] (変更)`HeapFile::new`に`MemoryDiskManager`を渡す．操作の結果は`Result`になり，`tuples`はタプルを`Vec<u8>`で返す
- [x] ファイルに置いたタプルは，ヒープファイルを開き直しても読める

### catalog

- [x] 保存したカタログを読み込むと，同じ表の定義がある(日本語の名前，`NOT NULL`，一意性制約を含む)
- [x] カタログのファイルがなければ，表のないカタログになる
- [x] カタログのファイルは，表の数，表の名前，列の数の順に始まる
- [x] 途中で終わるカタログのファイルは，`InvalidData`のエラーになる

### error

- [x] ファイルの読み書きのエラーは，`58030`と`could not access file: ...`になる

### exec::dml

- [x] (変更)テストの`HeapFile`を`MemoryDiskManager`で作る

## 結合テスト

### persistence

- [x] 表を作り，行を追加，更新，削除してから開き直すと，同じ行が読める．一意性制約も残る
- [x] 削除した表は，開き直しても存在しない．同じ名前で別の表を作れる
- [x] データディレクトリには，`catalog`と，表ごとのヒープファイル(`T`なら`54.heap`)がある
- [x] データディレクトリを使わない`Database::new`は，ファイルの表を読まない

### そのほか(既存)

- [x] メモリーのデータベースで，引き継いだ結合テストがすべて通る
