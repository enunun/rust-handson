# テストリスト

## 単体テスト

### lexer

- [x] `'abc'`からは，文字列`abc`のトークンを返す
- [x] `''`からは，空の文字列のトークンを返す
- [x] `'it''s'`の`''`は，1つの引用符`'`になる
- [x] 文字列の中の空白と日本語は，そのまま残る
- [x] `1 'abc`のように閉じていない文字列は，開きの引用符の位置3のエラーになる
- [x] `'a'||'b'`からは，文字列，連結演算子，文字列を返す
- [x] `'あ' ?`のエラーの位置は，バイトではなく文字で数えて5になる

### parser

- [x] `'abc'`は，文字列の定数になる
- [x] `'a' || 'b' || 'c'`は`('a' || 'b') || 'c'`になる(左結合)
- [x] `1 + 2 || 'x'`は`(1 + 2) || 'x'`になる(加算が先)
- [x] `'a' || 'b' = 'ab'`は`('a' || 'b') = 'ab'`になる(比較が後)

### eval

- [x] `'abc'`は，文字列の値になる
- [x] `'it''s' || ' ok'`は，`it's ok`になる
- [x] 連結の片方が`NULL`なら，`NULL`になる
- [x] `'a' || 1`は，型の不一致のエラーになる
- [x] 文字列はコードポイントの順に比べる(`'B' < 'a'`，`'' < 'a'`，`'ab' < 'b'`，`'z' < 'あ'`)
- [x] `'1' = 1`は，型の不一致のエラーになる
- [x] `'a' + 1`，`-'a'`，`NOT 'a'`は，型の不一致のエラーになる

## 結合テスト

### values

- [x] `VALUES ('it''s' || ' ok', 'a' < 'b')`は，`it's ok`と真の行になる
- [x] `VALUES ('日本語' ? 1)`は，文字で数えた位置15の字句解析のエラーになる
