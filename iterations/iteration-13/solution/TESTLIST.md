# テストリスト

## 単体テスト

### storage::tuple

- [x] 値は，`NULL`のビットマップのあとに，`INTEGER`は4バイト，`BIGINT`は8バイト，`BOOLEAN`は1バイト，`VARCHAR`は2バイトの長さとUTF-8のバイト列で並ぶ
- [x] `NULL`の列はビットマップのビットを1にし，値のバイトを持たない
- [x] 9列の表のビットマップは2バイトである
- [x] 符号化した行を復号すると，元の行に戻る(最小値と最大値，空の文字列，すべて`NULL`の行)
- [x] 途中で終わるタプル，`0`と`1`以外の`BOOLEAN`，UTF-8でない文字列は，復号のエラーになる

### storage::page

- [x] 置いたタプルは，スロットの番号で読める．ないスロットは`None`になる
- [x] タプルはページの末尾から前へ詰め，ヘッダーとスロットに位置と長さを書く
- [x] 消したタプルは読めなくなり，スロットの番号はほかのタプルに使わない
- [x] 更新は，小さくなればその場所に書き，大きくなれば空いている領域に置き直す
- [x] 空きが足りなければ`PageFull`になり，元のタプルは残る
- [x] 8184バイトのタプルは置けるが，8185バイトのタプルは`TupleTooLarge`になる

### storage::heap

- [x] 最後のページに入らないタプルは，新しいページに置く
- [x] タプルはページとスロットの順に並び，消したタプルは含まない
- [x] 同じページに入らなくなった更新は，タプルを別のページに移し，新しい`RowId`を返す
- [x] どのページにも入らないタプルは`TupleTooLarge`になり，ページを加えない

### exec::dml

- [x] テストの表を，行をタプルにして置いた`HeapFile`で渡す．結果は`HeapFile`から読んだ行で比べる
