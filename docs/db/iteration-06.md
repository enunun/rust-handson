# Iteration 6：クライアントと結果の表示

## 対話的なクライアント

データベースを使う人は，`psql`(PostgreSQL)，`sqlite3`，`mysql`のような対話的なクライアントでSQLを入力する．
クライアントは入力を文に区切ってデータベースに送り，返ってきた結果を表示する．

`;`は，SQLの文の一部ではなく，クライアントが文の終わりを知るための区切りである．
クライアントは，文字列リテラルや区切り識別子の中の`;`を区切りとみなさない．

## 結果集合とコマンドタグ

問い合わせ(`SELECT`や`VALUES`)の結果は，列の名前と行の並びからなる結果集合である．
行を返さない文(`CREATE TABLE`，`INSERT`など)は，何をしたかを表す短い文字列(コマンドタグ)を返す．

| 文 | コマンドタグ |
| --- | --- |
| `CREATE TABLE` | `CREATE TABLE` |
| `INSERT` | `INSERT 0 行の数` |

`INSERT`のタグの`0`は，PostgreSQLの古い版で使われていた値の名残で，今は常に0である．
コマンドタグは，Iteration 20でPostgreSQLのプロトコルの`CommandComplete`メッセージとして返す．

## 結果の表示

`ferrodb`のREPLは，`psql`の整列形式に似た表で結果を表示する．

```text
 ID | NAME
----+-------
  1 | alice
  2 | bob
(2 rows)
```

- 列の幅は，見出しとすべての値のうち最も長いものに合わせる．
- 見出しは中央に，数値は右に，文字列などは左に寄せる．
- `NULL`は空欄で，真偽値は`t`と`f`で表示する(`psql`の既定と同じ)．
- 最後に行の数を書く．

結果集合の中の`NULL`と空の文字列は，この表では同じ空欄に見える．区別が必要なときは`IS NULL`で調べる．
