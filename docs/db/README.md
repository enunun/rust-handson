# データベースのノート

各Iterationで初めて扱うデータベースの理論を説明する．

| Iteration | 内容 |
| --- | --- |
| [0](iteration-00.md) | SQLの処理の流れ，字句解析とトークン，`VALUES` |
| [1](iteration-01.md) | 構文木，演算子の優先順位と結合性，`INTEGER`型と範囲外の例外，`VALUES`の列名 |
| [2](iteration-02.md) | `NULL`，3値論理，`IS NULL`，比較，演算子の優先順位 |
| [3](iteration-03.md) | 文字列リテラル，文字列型，連結，照合順序，文字で数えるエラーの位置 |
| [4](iteration-04.md) | SQLSTATEのクラスとサブクラス，エラーの位置，構文解析のバックトラック |
| [5](iteration-05.md) | 表とスキーマ，カタログ，識別子，データ型，代入の規則，文の原子性 |
| [6](iteration-06.md) | 対話的なクライアント，文の区切り，結果集合とコマンドタグ，結果の表示 |
| [7](iteration-07.md) | `SELECT`の処理の順序，名前解決，`WHERE`と3値論理，選択項目と列名 |
| [8](iteration-08.md) | `UPDATE`と`DELETE`，整合性制約(`NOT NULL`，`UNIQUE`，`PRIMARY KEY`)，制約の名前，文単位の原子性，制約を検査する時点 |
| [9](iteration-09.md) | `SELECT`の処理の順序，`ORDER BY`と名前の解決，`NULL`の並び順，`OFFSET`と`FETCH FIRST`，`DISTINCT` |
| [10](iteration-10.md) | 問い合わせの処理の段階，論理計画と物理計画，Volcanoモデル，パイプラインとブロッキング演算子，`EXPLAIN` |
| [11](iteration-11.md) | 直積，内部結合，外部結合と`ON`と`WHERE`の違い，表の別名と修飾した列名，入れ子ループ結合 |
| [12](iteration-12.md) | 集約関数と`NULL`，`GROUP BY`，集約する問い合わせで使える式，`HAVING`と処理の順序，ハッシュ集約 |
| [13](iteration-13.md) | ページ，タプルの符号化と`NULL`のビットマップ，スロット付きページ，行の位置(TID)，ヒープファイル |
| [14](iteration-14.md) | データディレクトリ，ヒープファイルとページの位置，ページを読み書きする層，カタログ，名前の変更による置き換えと耐久性，起動の流れ |
| [15](iteration-15.md) | バッファプールと枠，ヒットとミス，書き戻しと変更の印，ピン留め，置換の方針，クロック方式 |
| [16](iteration-16.md) | インデックス，B+木の葉と内部ノード，ファンアウトと高さ，検索と範囲の走査，挿入と分割，メタページ，削除，順序を保つキーの符号化，同じキーの項目 |
